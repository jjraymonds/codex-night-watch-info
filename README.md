# Codex Night Watch

**A privately maintained Windows companion utility for Codex Desktop.**

Codex Night Watch is a personal Windows application designed to monitor Codex usage-limit interruptions and safely resume eligible Desktop sessions after verified subscription quota resets.

The application provides recovery monitoring, session diagnostics, configurable visual themes, and optional read-only community reset information.

## Project Availability

Night Watch is currently developed and maintained for private, personal use.

**This repository is an informational and contact page only.**

It does not contain the application's source code, executable files, configuration, operational logs, or development materials.

Night Watch is not currently distributed or supported as publicly downloadable software.

## Contact

For questions about Night Watch or its third-party integrations, please use this repository's **Issues** tab to contact the maintainer.

## Third-Party Information

Night Watch optionally uses public information from [codex-reset.com](https://codex-reset.com/) to display community reset forecasts and related service information.

These forecasts are informational only. They do not verify personal account quota availability or authorize automatic recovery.
